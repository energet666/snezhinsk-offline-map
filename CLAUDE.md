# map-offline — заметки для Claude

Офлайн-карта Снежинска (Челябинская область) на Leaflet, данные — GeoJSON из OSM (через Overpass API).

## Конвенции

- Локальный dev-сервер всегда запускать на порту 5173 (`./run.sh` использует 5173 по умолчанию).
- Проверки через Playwright: в `page.evaluate` не возвращайте объекты Leaflet — `map.setView(...)`/`marker.openPopup()` возвращают сам объект карты/маркера, и Playwright намертво зависает, пытаясь сериализовать этот цикличный граф с DOM-узлами. Пишите `page.evaluate("map.setView(...); null")`. Ещё: `server.py` однопоточный (`socketserver.TCPServer`), пачка параллельных запросов тайлов в режиме Спутник его подвешивает — в тестах лучше дёргать обработчик напрямую (`map.fire('baselayerchange', …)`) или блокировать `**/tiles/**`.
- `TODO.txt` — личный рабочий список пользователя, в CP1251. Читать через `iconv -f CP1251 -t UTF-8 TODO.txt`. Не коммитить изменения в этот файл — это черновик пользователя, не часть репозитория по сути (хотя физически лежит в директории).
