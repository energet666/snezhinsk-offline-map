# map-offline — заметки для Claude

Офлайн-карта Снежинска (Челябинская область) на Leaflet, данные — GeoJSON из OSM (через Overpass API).

## Конвенции

- Локальный dev-сервер всегда запускать на порту 5173 (`./run.sh` использует 5173 по умолчанию).
- `TODO.txt` — личный рабочий список пользователя, в CP1251. Читать через `iconv -f CP1251 -t UTF-8 TODO.txt`. Не коммитить изменения в этот файл — это черновик пользователя, не часть репозитория по сути (хотя физически лежит в директории).

**Важно про Overpass API**: HTTPS до `overpass-api.de`/зеркал не проходит из этого окружения (TLS/сеть блокируется), но **plain HTTP работает** (`http://overpass-api.de/api/interpreter`). Также area-запросы (`area["name"="Снежинск"]...`) часто выдают "server too busy" — используйте `[bbox:56.0229,60.6445,56.1211,60.8203]` в заголовке запроса вместо `area`, это стабильно быстрее.

**Источники актуальных данных об организациях (исследование, 3 сессия)**:
- **2GIS** — юридически закрыт (см. README, п. 5.1.2/5.1.4/5.1.8 лицензии) — извлечение данных в свою БД запрещено.
- **Yandex Maps API/Геокодер** — та же проблема: условия использования прямо запрещают сохранять/кэшировать полученные через API данные (координаты, адреса, объекты) на своей стороне — не подходит для офлайн-БД по той же причине, что и 2GIS.
- **ЕГРЮЛ/ЕГРИП (ФНС)** — официальный бесплатный реестр юрлиц/ИП (данные открыты по 129-ФЗ), но: (а) даёт только факт регистрации по адресу, не факт физического присутствия в здании (много юрлиц регистрируются "на бухгалтера", по домашним адресам и т.д., и наоборот — реальные точки часто ИП/филиалы без отдельной записи); (б) нет готовой геопривязки, нужен свой геокодинг; (в) бесплатно только через веб/по одному ИНН, массовый экспорт — только у платных агрегаторов (zachestnyibiznes.ru, api-fns.ru). Вывод: не решает проблему актуальности лучше, чем OSM, для конкретно "какая организация сидит в здании X".
