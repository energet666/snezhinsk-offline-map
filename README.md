# Оффлайн-карта Снежинска

Полностью автономное веб-приложение с картой Снежинска (Челябинская область):
- режим **«Карта»** — улицы, дома с номерами, организации (данные OpenStreetMap)
- режим **«Спутник»** — снимки Esri World Imagery
- слой **«Названия и объекты»** можно включить поверх спутника (как гибридный режим Google Maps)
- поиск по улицам, номерам домов и организациям

Всё работает без интернета после первого запуска — данные и тайлы уже скачаны и лежат локально.

## Запуск

```bash
cd /root/playground/map-offline
python3 server.py
```

Откройте http://localhost:8765 в браузере.

Сервер — обычный `http.server`, интернет ему не нужен: все ресурсы (Leaflet, GeoJSON-данные, тайлы) уже находятся в этой папке.

## Структура

- `data/*.geojson` — улицы, здания (с номерами домов), организации/POI, водоёмы, зелень, ж/д — выгружены из OpenStreetMap (Overpass API) в границах Снежинска.
- `tiles/{z}/{x}/{y}.png` — растровые спутниковые тайлы Esri World Imagery, зумы 10–17 (~3300 тайлов, 49 МБ), покрывают город с запасом.
- `lib/` — локальная копия Leaflet 1.9.4 (карта не зависит от внешних CDN).
- `index.html`, `app.js`, `style.js`, `style.css` — само приложение.
- `server.py` — локальный сервер на стандартной библиотеке Python.

## Ограничения и что можно улучшить

- **Покрытие данных** ограничено окрестностями города (буфер ~2–4 км за границей застройки) — этого достаточно для города и подъездов к нему, но не для области целиком.
- **Названия улиц** в OSM указаны не для всех проездов (170 из 1609 линий дорог имеют name) — это ограничение исходных данных OSM для Снежинска, а не приложения.
- **Спутник**: максимальный явно скачанный зум — 17 (~0.6–1 м/пиксель на этой широте), при увеличении дальше Leaflet будет растягивать эти же тайлы (`maxNativeZoom`). Если нужна более высокая детализация — можно перезапустить `download_tiles.py` (в истории сессии) с `MAX_Z=18` для более точной зоны.
- **Спутник — источник данных**: Esri World Imagery, лицензия допускает офлайн-использование в некоммерческих целях. Прямое массовое скачивание тайлов Google Maps для офлайна нарушает условия использования Google, поэтому не использовалось.
- Для актуализации данных (новые дома/организации) нужно заново выполнить Overpass-запрос и обновить `data/*.geojson`.
